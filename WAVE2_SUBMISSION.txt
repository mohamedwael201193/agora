# AGORA - WAVE 2 SUBMISSION

## What is Agora?
Agora is a decentralized prediction market platform on Linera blockchain where users create markets, place predictions, and trade outcomes with real-time settlement.

### Tech Stack
- **Contracts:** Linera SDK 0.15.6, Rust + Wasm, GraphQL service
- **Frontend:** React 18, TypeScript 5.5, Vite, Zustand, TailwindCSS
- **Validators:** 4 Conway nodes (validator-1 to validator-4.testnet-conway.linera.net)

### Deployment Command
```bash
linera publish-and-create \
  agora_contract.wasm agora_service.wasm \
  --json-parameters '{"registry_chain_id":"134f497810..."}'
```

### Features
1. **Market Creation** - Custom questions, multiple outcomes, deadlines, on-chain storage
2. **Wallet** - Conway wallet import, balance display, IndexedDB persistence
3. **Marketplace** - Browse live markets with real-time blockchain updates
4. **Predictions** - Token-staked predictions on any outcome
